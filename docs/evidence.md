# Stage Evidence

This document maps implemented functionality and test results to the two stage competencies.

## Competency 1

**Installeert en configureert netwerk- en infrastructuuronderdelen**

Evidence will be added as installation, configuration procedures and validation tests are completed.

## Competency 2

**Beheert en monitort netwerk- en infrastructuuronderdelen**

Evidence will be added as management, monitoring, diagnostics and reporting capabilities are completed.

## Evidence standard

Each evidence item should identify:

- objective
- environment
- procedure
- command/script used
- expected result
- actual result
- conclusion
- supporting log or screenshot when appropriate
