# Begrippenlijst

| Begrip | Betekenis in NetworkLab |
|---|---|
| API | Interface waarmee onderdelen van de webapp gegevens of acties uitwisselen |
| DHCP | Dienst die automatisch IP-configuratie aan clients kan toekennen |
| DNS | Dienst die namen naar netwerkadressen vertaalt |
| Gast-OS | Besturingssysteem binnen een virtuele machine |
| Host | Fysieke Windows-computer waarop NetworkLab en VirtualBox draaien |
| Host-only | VirtualBox-netwerkmodus voor communicatie tussen host en gekoppelde VM's binnen een virtueel segment |
| IPv4 | Internet Protocol versie 4, gebruikt voor netwerkadressering |
| Lease | Tijdelijke DHCP-toekenning van een IP-adres en bijbehorende opties |
| localhost | Naam/adres voor de lokale computer; hier gebruikt als 127.0.0.1 |
| MGMT | Managementrol van de eerste lab-VM |
| INFRA | Infrastructuurrol van de tweede lab-VM |
| CLIENT | Clientrol van de derde lab-VM |
| Monitoring | Herhaald of gericht verzamelen van statusinformatie |
| Prefix /24 | IPv4-prefix die overeenkomt met subnetmasker 255.255.255.0 |
| Rollback | Gecontroleerd terugdraaien naar de vorige bekende configuratie |
| TCP | Transportprotocol voor verbindingen tussen applicaties |
| Topologie | Beschrijving van netwerkcomponenten en hun verbindingen |
| VDI | VirtualBox Disk Image, bestandsformaat voor virtuele schijven |
| VM | Virtuele machine die hardware en een computeromgeving simuleert |
| VBoxManage | Opdrachtregelprogramma om VirtualBox te beheren |
| Bewijsstuk | Screenshot, log, uitvoer of rapport dat een werkelijk uitgevoerde activiteit onderbouwt |
| Openstaand | Een test of taak die nog niet is uitgevoerd of geverifieerd |
