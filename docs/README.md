## Statusconventie

Documentatie beschrijft de bedoelde werkwijze en bekende configuratie. Alleen werkelijk uitgevoerde controles mogen als geslaagd worden geregistreerd. Gebruik:
- **Geslaagd** — de controle is uitgevoerd en voldoet aan het criterium.
- **Mislukt** — de controle is uitgevoerd en voldoet niet aan het criterium.
- **Geblokkeerd** — uitvoering was niet mogelijk of niet veilig.
- **Openstaand/niet gemeten** — er is nog geen waarneming.

Een geplande configuratie, diagram of aanwezig script bewijst op zichzelf niet dat de omgeving werkt.
