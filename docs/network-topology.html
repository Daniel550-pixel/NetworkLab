2. Verkeersstromen en controles

Host → VM

Test de bereikbaarheid van elk gast-IP-adres vanaf Windows, bijvoorbeeld met ping. ICMP kan door de gastfirewall worden geblokkeerd; interpreteer dat resultaat samen met een aanvullende servicetest.

VM → VM

Test communicatie tussen de drie VM's nadat IP-adressen zijn vastgesteld. Leg bron, bestemming, opdracht en uitvoer vast.

DHCP

Controleer in Ubuntu met ip addr en ip route welk adres en welke route daadwerkelijk zijn toegekend.

Monitoring

Bewaar de uitvoer en tijdstempel. De softwarematige incidentensimulatie is geen bewijs van echte VM-connectiviteit.

3. Veilige scope

Deze topologie is bedoeld voor een geïsoleerde oefenomgeving. De tekening beschrijft de configuratie zoals die is voorbereid; niet alle verbindingen zijn al praktijktest-bevestigd. Er wordt geen fysieke netwerkbridge verondersteld en de incidentensimulatie verandert alleen de gesimuleerde projectstatus.
